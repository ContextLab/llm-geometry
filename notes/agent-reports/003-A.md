## Schema decisions (coordinate: 003-B and static client)

- **golden.json**: exactly `{cases, weight_edits, finetune}` (no extra top-level keys). cases = 3 prompts (plain Alice; unk: quantum/xylophone/blockchain; 62-token → truncated to 50) × 4 field configs (next_next full T=0; next_next layer1 T=1 top_m3; force layer0 anti=false/true). `fields[].params` keys: mode/layer/temperature/top_m/antisymmetrize; `response`/`trace` are verbatim 6-sig route JSON (rounding ≪ 1e-5 tolerance). weight_edits = 5 (identity W_Q L0, toeplitz_fuzzy W_V L1, random seed7 W_K L2, explicit-values W_O L3, embedding random seed7): `{body, weights_token, resolved}` where resolved = ALL 34 state_dict names ("embedding","pos_embedding","layers.i.{W_Q,W_K,W_V,W_O,W_in,b_in,W_out,b_out}") at full float precision (shortest-repr JSON → exact f32 round-trip). finetune: text/steps=50/lr=0.01/seed=0/loss_before=5.10043/loss_after=4.46853/weights_token, via real route + job poll.
- **checkpoint.json**: `{format, config (d_model,n_layers,n_heads,mlp_hidden,vocab_size,context_window,seed,tied_unembedding,corpus,special_tokens), metrics (checkpoint_id be5359a1c66bda29c8c554269e589009, final_loss 4.88521, coverage 0.90055, entropy 2.81215), weight_names, shapes, weights}` — full precision, asserted complete vs state_dict.
- **vocab.json**: `{format, vocab_size, specials{unk:0,eos:1,pad:2}, tokens[1003]}` (index = id).
- **tiles**: per param the exact full-window `/api/arch/weights` grid (≤64×64, strided_mean), uint8 with per-tile vmin/vmax in tiles.json (`value = vmin + u8/255*(vmax-vmin)`), offsets into tiles.bin.
- **presets**: `{schema_version, view, n, label, model_id, state, requests:[{endpoint, params, response}]}` — params are the EXACT query dicts the views send (verified against VectorField/Sankey/Manifold.svelte + stores.ts defaults; preset 1 = default state). Response-bearing presets also include the `/api/tokenize` call ResponseAnimator makes. token_cloud exported once (seed 0, spread_mu 0.65); views fetch no reduction_2d/token-cloud beyond this (checked dataClient usage).
- **--quick** (used by the test): geo full; arch gpt2 graph+tiles+2 traces; 1 small preset/view (gpt2).
