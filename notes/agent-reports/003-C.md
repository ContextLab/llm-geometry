## Safetensors reader (`safetensors.ts`)

u64-LE header len → cached JSON header → absolute ranges = 8+len+data_offsets. Full-width
windows = ONE range; narrow windows = single span fetch (≤ max(256KB, 4×wanted), ≤4MB) sliced
locally, else gap-coalesced (2KB) per-row ranges at concurrency 6. Insists on 206 (tolerates
Range-ignoring 200 only ≤32MB). Dtypes: F32, BF16 (u16<<16 bit pattern), F16 (manual, incl.
subnormals/inf/NaN). Param-name aliasing verified against REAL headers: gpt2's file drops the
`transformer.` prefix; tied `lm_head.weight` → embedding aliases; shape integrity-checked
against tiles.json.

webgpu/q4f16 → wasm/q8 ladder (shader-f16 checked); ONNX repos: SmolLM2→onnx-community/
SmolLM2-135M-Instruct-ONNX, gpt2→onnx-community/gpt2-ONNX, Qwen→onnx-community/

no seeded sampler — real samples, never faked determinism; ArchChat doesn't send seed).
Chat template applied when present (system+user, add_generation_prompt), else backend's
`"{system}\n\n{prompt}"`. REAL Node smoke run executed (gpt2-ONNX q8 downloaded): generate,
options, direct-forward logits [1,T,50257], teacher-forced argmax == greedy pick, pinned-revision
tokenizers + Qwen chat template all verified live.
