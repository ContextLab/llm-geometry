## Honest-affordance judgment calls

1. Boot applies preset-1 state (no-op on full exports since preset 1 == defaults —
   verified against presets/*/1.json) so quick exports render instantly too.
2. Arch tab auto-applies example 1 ONLY when the prompt is the untouched backend
   default and has no precomputed trace — opening on a note would be honest but
   hostile; user-typed prompts are never overridden.
3. Sankey highlight-only miss gets its own compact note (swarm stays valid); a
   retry button there would fake fixability.
4. ModelSelector in static mode no longer defaults the readout layer to the final
   layer: the preset states own it (documented in-code).
5. StaticNotice is styled as info (dashed accent), not error red: nothing is
   broken — the build just doesn't carry that computation (FR-203 wording shown
   verbatim from the data layer, which names what IS available).
