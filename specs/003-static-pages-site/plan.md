# Feature 003 plan: GitHub Pages static build ("live" mode)

Goal: the full app served from https://contextlab.github.io/llm-geometry/ with no
Python backend — per issue #1's "ideally it could run entirely in a browser".

## Runtime modes
- The frontend gains a data-layer switch: `backend` (existing dataClient, unchanged)
  vs `static` (new staticClient implementing the same interface). Mode chosen at
  build time (`VITE_DATA_MODE=static`) with runtime capability detection inside.

## Static data layer
1. **Geometry Lab — fully live in TS** (`src/lib/geoEngine/`):
   - Port GeoTransformer forward/trace/fields/weights/finetune to TypeScript with
     Float32Array (matmul/softmax/adam ≈ 300 lines) — numerically cross-checked
     against the Python backend in vitest (golden vectors exported at build time).
   - Checkpoint + tokenizer vocab shipped as JSON (~31 KB + ~15 KB) generated by a
     backend export script (scripts/export_static_assets.py) into
     code/frontend/public/static-data/.
   - Fine-tune runs in a Web Worker (real SGD, <1 s per 100 steps); presets +
     content-hash tokens computed client-side (same hash function, sessionStorage).
2. **Architecture Explorer — hybrid live/precomputed**:
   - Graph: precomputed JSON per curated model (424 nodes SmolLM2 etc.).
   - Weight inspector: LIVE exact windows via safetensors HTTP range-reads from
     huggingface.co/resolve/<pinned-commit>/ (CORS verified; bf16→f32 decode);
     overview tiles precomputed as uint8 .bin + manifest (~0.9 MB).
   - Tokenization strip: LIVE via transformers.js AutoTokenizer (vendored
     tokenizer.json, ~3.5 MB, no model download).
   - Generation/chat: LIVE via transformers.js v4 pipeline, device webgpu
     dtype q4f16 (117 MB from HF CDN) with wasm+q8 fallback; per-token probs from
     logits (direct forward calls).
   - Trace panel (per-layer attentions/hidden norms): NOT available from ONNX →
     precomputed traces for ~6 example prompts (dropdown), clearly labeled; the
     playback/diagram animation runs on the precomputed node_activations. Arbitrary
     -prompt tracing documented as full-stack-only. Model switching limited to the
     curated precomputed set in static mode; size gate still enforced client-side.
   - Degradation ladder: webgpu → wasm → tokenizer+precomputed only (banner).
3. **001 tabs (vector/sankey/manifold)**: need hidden states → precomputed
   artifacts for the default model + a curated set of (prompt, params) presets;
   free-text prompt disabled in static mode with a clear affordance ("run the full
   stack for arbitrary prompts" + link). Controls that only re-slice cached data
   (layer slider, playback, hover) stay fully interactive.

## Build + deploy
- scripts/export_static_assets.py: runs the real backend once (models cached in CI)
  and emits all precomputed JSON/.bin under code/frontend/public/static-data/.
- vite.config.ts: base = process.env.PAGES_BASE ?? "/" ("/llm-geometry/" in CI).
- .github/workflows/pages.yml: precompute (HF cache) → npm ci + VITE_DATA_MODE=static
  build → configure-pages@v6 → upload-pages-artifact@v5 (dist) → deploy-pages@v5;
  404.html = index.html copy. Enable Pages (build_type=workflow) via gh api.
- e2e: playwright project "static" serving dist/ with vite preview --base, asserting
  each tab works in static mode (geo fully; arch live-tokenize + precomputed trace +
  range-read window vs known values; 001 tabs preset flows).

## Verification
- Golden-vector tests: TS geoEngine outputs == Python backend outputs (1e-5).
- Red team of the static build via Playwright (per-tab agents, screenshots).
- Live URL smoke: after deploy, fetch the page + one range-read + geo field render.
